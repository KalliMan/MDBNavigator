# Contributing to MDBNavigator

Thanks for your interest in contributing!

## Contributor License Agreement

Before your pull request can be merged, you need to sign the [Contributor License Agreement](CLA.md). You only need to do this once.

When you open your first pull request, a bot will comment with instructions. To sign, reply on the pull request with:

```
I have read the CLA Document and I hereby sign the CLA
```

If the check doesn't update, comment `recheck`.

## Pull requests

1. Fork the repository and create a branch from `master`.
2. Keep changes focused: one feature or fix per pull request.
3. Make sure the backend builds (`dotnet build`) and the UI builds and lints (`npm run build`, `npm run lint` in `mdb-navigator-ui`).
4. Describe what the change does and why.
